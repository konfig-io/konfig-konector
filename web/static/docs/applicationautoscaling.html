AppScalingPolicy # GA

AppScalingPolicy is the Schema for managing Application Auto Scaling policies.

Example

# AppScalingPolicy — Application Auto Scaling
# Full-options example generated from the CRD schema. Optional fields are
# included with sample values; delete what you don't need. Field reference:
# https://konfig-konector.io/docs/applicationautoscaling.html#appscalingpolicy
apiVersion: aws.konfig.io/v1alpha1
kind: AppScalingPolicy
metadata:
  name: example-appscalingpolicy
  namespace: default
spec:
  policyName: example-appscalingpolicy
  policyType: TargetTrackingScaling
  providerRef:
    name: example-appscalingpolicy
    region: us-east-1
  scalableDimension: example
  serviceNamespace: example
  stepScalingConfiguration:
    adjustmentType: ChangeInCapacity
    cooldown: 1
    metricAggregationType: Average
    minAdjustmentMagnitude: 1
    stepAdjustments:
    - metricIntervalLowerBound: 1
      metricIntervalUpperBound: 1
      scalingAdjustment: 1
  targetRef:
    name: example-target
  targetTrackingConfiguration:
    disableScaleIn: false
    predefinedMetricType: example
    resourceLabel: example
    scaleInCooldown: 1
    scaleOutCooldown: 1
    targetValue: 1
