Caution, destructive scope: account-wide ACM settings singleton. Provided for completeness; do not use from application namespaces. Restrict with AWSProvider.allowedNamespaces and RBAC. ACMAccount manages AWS::CertificateManager::Account through the AWS Cloud Control API.
