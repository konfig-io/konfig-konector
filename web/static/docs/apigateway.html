RestAPI # GA

RestAPI is the Schema for managing API Gateway REST APIs.

kubectl get restapis · example on GitHub

Example

# RestAPI — API Gateway
# Full-options example generated from the CRD schema. Optional fields are
# included with sample values; delete what you don't need. Field reference:
# https://konfig-konector.io/docs/apigateway.html#restapi
apiVersion: aws.konfig.io/v1alpha1
kind: RestAPI
metadata:
  name: example-restapi
  namespace: default
spec:
  body: example
  description: Managed by konfig-konector
  disableExecuteApiEndpoint: false
  endpointTypes:
  - example
  minimumCompressionSize: 2
  name: example-restapi
  policy: '{"Version": "2012-10-17", "Statement": [{"Effect": "Allow", "Action": ["s3:GetObject"], "Resource":
    "*"}]}'
  providerRef:
    name: example-restapi
    region: us-east-1
  tags:
    environment: dev
    team: platform
