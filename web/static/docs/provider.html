Multi-Account Provider

1 resource kind. Generated from the operator's CRD schemas.

API Group: aws.konfig.io/v1alpha1

AWSProvider # GA

AWSProvider is a cluster-scoped credential and region target that resources select with spec.providerRef.

kubectl get awsproviders · example on GitHub

Example

# AWSProvider — Multi-Account Provider
# Full-options example generated from the CRD schema. Optional fields are
# included with sample values; delete what you don't need. Field reference:
# https://konfig-konector.io/docs/provider.html#awsprovider
apiVersion: aws.konfig.io/v1alpha1
kind: AWSProvider
metadata:
  name: example-awsprovider
  namespace: default
spec:
  allowedNamespaces:
  - example
  default: false
  durationSeconds: 900
  region: us-east-1
  roleArn: arn:aws:iam::123456789012:role/example-role
  sessionName: example-awsprovider
  sourceProviderRef:
    name: example-awsprovider
    region: us-east-1
