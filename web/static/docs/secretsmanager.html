4 resource kinds. Generated from the operator's CRD schemas.

Secret # GA

Secret is the Schema for managing AWS Secrets Manager Secrets.

kubectl get secrets · example on GitHub

Example

# Secret — Secrets Manager
# Full-options example generated from the CRD schema. Optional fields are
# included with sample values; delete what you don't need. Field reference:
# https://konfig-konector.io/docs/secretsmanager.html#secret
apiVersion: aws.konfig.io/v1alpha1
kind: Secret
metadata:
  name: example-secret
  namespace: default
spec:
  description: Managed by konfig-konector
  forceDelete: false
  kmsKeyArn: arn:aws:iam::123456789012:role/example-role
  providerRef:
    name: example-secret
    region: us-east-1
  recoveryWindowInDays: 1
  secretName: example-secret
  secretStringRef:
    key: example
    name: example-secret
  tags:
    environment: dev
    team: platform

Spec

providerRef.namestringyesName of a cluster-scoped AWSProvider.
providerRef.regionstring—Region overrides the provider's region for this resource only.
recoveryWindowInDaysinteger—RecoveryWindowInDays is the number of days before permanent deletion (7-30).
secretNamestringyesSecretName is the name of the secret.
secretStringRefobject—SecretStringRef is a reference to a Kubernetes Secret containing the secret value.
secretStringRef.keystringyesKey is the key within the Secret whose value to use.

tagsmap<string>—Tags are AWS resource tags to apply.
