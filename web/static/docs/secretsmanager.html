Secret # GA

Secret is the Schema for managing AWS Secrets Manager Secrets.

kubectl get secrets · example on GitHub

Example

# Secret — Secrets Manager
# Full-options example generated from the CRD schema. Optional fields are
# included with sample values; delete what you don't need. Field reference:
# https://konfig-konector.io/docs/secretsmanager.html#secret
apiVersion: aws.konfig.io/v1alpha1
kind: Secret
metadata:
  name: example-secret
  namespace: default
spec:
  description: Managed by konfig-konector
  forceDelete: false
  kmsKeyArn: arn:aws:iam::123456789012:role/example-role
  recoveryWindowInDays: 1
  secretName: example-secret
  secretStringRef:
    key: example
    name: example-secret
  tags:
    environment: dev
    team: platform
