API Reference

1061 resource kinds across 158 AWS services, all under the aws.konfig.io/v1alpha1 API group. Every page is generated from the operator's CRD schemas; every kind has a full-options example in the examples/ directory.

Coverage policy. GA kinds have hand-written controllers. CLOUD CONTROL kinds are generated from the CloudFormation schema registry and reconciled through the AWS Cloud Control API; install them per service bundle from config/crd/cloudcontrol/. ⚠ DESTRUCTIVE SCOPE marks 36 kinds that change account-, region- or organization-wide state (or must carry credential material in their spec). They exist for completeness and should not be used from application namespaces; restrict them with AWSProvider.allowedNamespaces and RBAC.

Deliberately excluded. Billing, Invoicing, Cost and Usage Reports, BCM Data Exports, Budget actions and payment connectors are not generated: automating account finances from a cluster is a liability, not a platform capability. They remain reachable through the generic CloudControlResource.
