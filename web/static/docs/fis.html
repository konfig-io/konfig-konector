Caution, destructive scope: fault injection into another account. Provided for completeness; do not use from application namespaces. Restrict with AWSProvider.allowedNamespaces and RBAC. FISTargetAccountConfiguration manages AWS::FIS::TargetAccountConfiguration through the AWS Cloud Control API.
